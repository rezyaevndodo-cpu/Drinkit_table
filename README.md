# Drinkit Омск — таблица статистики

Отдельный Railway-сервис. Собирает 20 метрик по 6 точкам Drinkit + «Вся сеть», пишет в Google Sheets каждый день в 07:30 Омск.

## Метрики
Выручка · Выручка моб.приложение · Заказы · Заказы моб. · % моб. · Средний чек · Часы кухни · Производительность · Продуктивность · Время на трекинге · Сервисное время · Рейтинг клиентов · Доля оценённых · Доступность меню · Продуктов в стопе · Списания всего · % списаний · Списания (срок/порча/чел.фактор/маркетинг)

## Деплой на Railway

### 1. Новый GitHub-репозиторий
Залить все файлы (через git, чтобы папка src/ сохранилась).

### 2. Railway → New Project → Deploy from GitHub repo

### 3. Variables
| Переменная | Значение |
|---|---|
| `DODO_CLIENT_ID` | `cpmmr` |
| `DODO_CLIENT_SECRET` | `IVLoxNZFDzSkhbQHSTB5xhFpOMRvYeuB` |
| `DODO_REFRESH_TOKEN` | (свежий refresh для cpmmr) |
| `GOOGLE_SHEET_ID` | (ID новой таблицы Drinkit) |
| `GOOGLE_SERVICE_ACCOUNT_B64` | (тот же ключ что у таблицы Dodo) |
| `PORT` | `8080` |

### 4. Google Sheets
- Создать новую таблицу
- Открыть доступ service-account (тому же что у Dodo) на редактирование
- ID таблицы → в `GOOGLE_SHEET_ID`

### 5. После деплоя
- URL + `/run` — первый запуск вручную
- Листы «По дням», «По неделям», «По месяцам» заполнятся
- Дальше авто-обновление 07:30 Омск

## Особенности
- Накопление с 1 мая 2026 (как Dodo)
- Текущий незавершённый день не выводится
- «Вся сеть» — серая строка-агрегат внизу
- Доступность меню: формула по рабочему времени 07:00–22:00, MENU_SIZE=190
- Списания по writtenOffAtLocal (правильные границы дня)
- Refresh одноразовый: получил → сразу в Railway, без локальных тестов

## Недоступные метрики (нет в API Drinkit)
Часы по графику, % долгих/нормальных/идеальных, новые/старые клиенты, себестоимость, % стажёров — эндпоинтов нет. KitchenCost — нужен scope `incentives` для cpmmr (включить на developer.dodois.io).
